# Документация ICU

[English](../en/index.md) · **Русский** · [Главная репозитория](../../README.md)

ICU — проект Friday Night Funkin' на основе Codename Engine, интегрированный в исходники. Начните с раздела [Об ICU](about.md), затем выберите инструкцию сборки, если хотите собрать игру самостоятельно.

- [Об ICU](about.md): концепция, структура исходников и основа движка.
- [Изменения движка](engine-features.md): дополнения ICU, унаследованные системы и ограничения платформ.
- [Зависимости](dependencies.md): общие инструменты, версии библиотек и Git-ревизии.
- [Сборка Windows](build-windows.md): настройка, typecheck, нативная сборка и ошибки.
- [Сборка Android](build-android.md): отдельный профиль hxcpp, ARM-архитектуры, APK и сенсорное управление.
- [HUD и HScript](hud-api.md): некоторые примеры.
- [Публичный журнал изменений](changelog.md): значимые изменения без вымышленных номеров релизов.

## Как читать сведения о проверках

Наличие реализации в исходниках, успешный Haxe typecheck, полная нативная сборка и проверка на устройстве подтверждают разные вещи. В инструкциях указано, какие результаты доступны. Прежние Android-сборки и отдельные проверки на телефоне были успешными; полный актуальный Windows EXE и все игровые сценарии Android пока не подтверждены.
