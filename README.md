# Friday Night Funkin': In Crish's Universe

![Banner](art/banner.png)

**English** · [Русский](#русский)

**In Crish's Universe (ICU)** is a Friday Night Funkin' project inspired by the work of Alex Crish, built on **Codename Engine**. ICU integrates its content and engine changes directly into the source tree. Build this repository to get ICU; copying it into another engine's `mods/` folder is not an installation method.

ICU adds English/Russian interface support, redesigned options, Classic, Crazy Stories and Legacy menu themes (Legacy is in development), startup videos, a customizable HUD and an Android port with touch controls. Translation and device coverage remain incomplete; see the documented verification limits.

## Русский

[English](#friday-night-funkin-in-crishs-universe) · **Русский**

**In Crish's Universe (ICU)** - проект Friday Night Funkin' по творчеству Алекса Криша, основанный на **Codename Engine**. Контент ICU и изменения движка встроены непосредственно в исходники. Для получения ICU нужно собрать этот репозиторий; копирование в папку `mods/` другого движка не является способом установки.

ICU добавляет английский и русский интерфейсы, переработанные настройки, темы меню Classic, Crazy Stories и Legacy (Legacy в разработке), стартовые видео, изменяемый HUD и Android-порт с сенсорным управлением. Перевод и охват устройств пока неполные; границы проверок указаны в документации выше.

Codename Engine remains the engine foundation / Codename Engine остаётся основой проекта. See [project credits](docs/en/about.md#credits) / [благодарности](docs/ru/about.md#благодарности). Existing [LICENSE](LICENSE) is preserved; this README adds no licensing terms.
